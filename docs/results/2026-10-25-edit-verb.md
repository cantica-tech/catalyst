- **Design 31, phase 3** (`fw-STRUCTURE-000021`): `catalyst edit <ID> --field NAME=VALUE --section HEADING=TEXT`
  changes an entity's plain fields and sections, journaled. It never edits `ID`, `Name`, `Filename`, `Signed-off-by`,
  `Status` or a derived field, and leaves references to `link`. An admin's edit is made (`--preview`, `--forewarned`);
  anyone else edits only an entity of theirs, directly when it is linked to nothing, else as a proposal an admin
  decides (decisions 31.2 and 31.3). `spec/change.schema.json` gains the optional `proposal`.
